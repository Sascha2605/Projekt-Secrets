# Projekt-Dokumentation

## Ziel
In diesem Repository beschäftige ich mich mit GitHub Secrets und deren Verwendung in GitHub Actions.

## Inhalte
- Erstellung von Repository Secrets
- Verwendung von Secrets in Workflows
- Sicherheitsmaßnahmen und Best Practices
- Automatisierung mit GitHub Actions

## Verwendete Technologien
- GitHub
- GitHub Actions
- YAML

## Praktische Umsetzung
Es wird ein Secret namens DOCS_DEPLOY_TOKEN erstellt und in einem GitHub-Actions-Workflow verwendet.

Das Secret wird nicht im Quellcode gespeichert oder in den Workflow-Logs ausgegeben.
